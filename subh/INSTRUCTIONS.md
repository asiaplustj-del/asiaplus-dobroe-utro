# Объединённая утренняя рубрика: «Хабарҳои шаби гузашта» + «Обу ҳаво / қурби асъор» (YouTube Shorts, Азия-Плюс)

Один ролик ~38 с (решение пользователя 21.11.2026): главная новость ночи крупно → список (до 22 с) → переход
«рассвет» → погода в Душанбе, Хуҷанде, Бохтаре, Хоруғе и курс RUB/USD/EUR к сомони (рубль первым).
Прежние отдельные рубрики «Хабарҳои шаб» (`khabar/`) и «Доброе утро» (`dobroe/`, навык dobroe-utro) приостановлены,
их инструкции не удалены — правила отбора новостей и сбора данных берём оттуда (ссылки ниже).
Публикация в **07:00** через YouTube Data API — **автоматически, без согласия пользователя** (он в это время спит;
постоянное разрешение для обеих рубрик). Metricool не используется. Технические препятствия решай сам, чтобы выпуск
вышел вовремя. Отвечай по-русски, в начале каждого сообщения — дата и время (Душанбе). Всё, что пользователь должен
прочитать, — SendUserMessage; файлы — SendUserFile со status "proactive". Заведи список задач и иди без вопросов.

## 1. Подготовка
- Время (Asia/Dushanbe): D — сегодня, P — вчера. Окно новостей: `P 18:00` → сейчас.
- Репозиторий: как в `khabar/INSTRUCTIONS.md` §1 (клон, git config, playwright + numpy + ffmpeg).
- Сайты-источники среда не открывает напрямую — всё через GitHub Action `khabar-fetch` (§1 той же инструкции:
  заявка `khabar/requests/<id>.txt` → push → ждать `khabar/fetched/<id>/_done.json` циклом через Bash).

## 2. Новости (шаги 2–4 из `khabar/INSTRUCTIONS.md` без изменений)
Сбор лент, отбор 6 пунктов (минимум 5, максимум 7; простой популярный контент для большинства населения,
редакционная линия), заголовки на простом литературном таджикском (35–65 знаков), фото у каждого пункта.
Итог — `work/news.json`: `{"date":"<D>","items":[{"cat","text","img"}...],"sources":[корневые адреса]}`, фото в `work/img/`.

## 3. Погода и курс
`mkdir -p work && bash dobroe/fetch.sh <D> work/weather.json` (таймаут 600000). Скрипт кладёт заявку `du-<D>`,
ждёт Action и собирает data.json (курс НБТ на D и P, прогноз meteo.tj — блок, датированный сегодня).
Сверь `data` с `raw`. `ok:false` (нет блока погоды на сегодня) — подожди 20 мин, удали `khabar/fetched/du-<D>` и
`khabar/requests/du-<D>.txt`, commit+push, повтори один раз. Делай этот шаг после новостей (ближе к 06:30).

## 4. Рендер
- Набор: `subh/kit/` (khabar.html, weather.html, dawn.html, render.py) → скопируй в `work/`.
- Шрифты: `khabar/kit/fonts/*` (fonts.css, Nunito) → `work/fonts/`; SF Pro и музыка — из закрытого набора
  (в публичный репозиторий не класть!): Artifact read https://claude.ai/artifact/KUoKz3ih32GVd1Diji362B, paths
  ["kit/fonts/SF-Pro-Display-Medium.otf","kit/fonts/SF-Pro-Display-Semibold.otf","kit/fonts/SF-Pro-Display-Bold.otf","kit/music.mp3"]
  → .otf в `work/fonts/`, music.mp3 в `work/music.mp3`. Без SF Pro не рендерить.
- `cd work && python3 render.py news.json weather.json subh_<D>.mp4` (таймаут 600000). Печатает компоновку:
  `fs` (кегль списка) ниже 40 — заголовки длинные, сократи; `total` ≈ 38 с.
- Проверка кадров (`ffmpeg -ss … -frames:v 1` → Read): 3.5 с (главная), 18 с (список), 30 с (погода и курс) —
  текст не обрезан, буквы ҳ ҷ қ ғ ӯ ӣ на месте, цифры погоды/курса совпадают с данными, дата «P–D <месяц> (<день недели>)».
- Дизайн, тайминги и звук не менять без просьбы пользователя.

## 5. Хостинг
`subh/videos/<D>.mp4` и обложку `subh/videos/<D>.jpg` (render.py кладёт `subh_<D>.jpg` рядом с MP4 — кадр 2,5 с,
собранная главная новость; посмотри его через Read) → commit «Утренний выпуск <D>» → push → `curl -sIL https://raw.githubusercontent.com/asiaplustj-del/asiaplus-dobroe-utro/main/subh/videos/<D>.mp4`
(content-length = размер файла).

## 6. Контроль перед публикацией
Публикуй, только если всё верно:
- новости — по §7 `khabar/INSTRUCTIONS.md` (≥ 5 пунктов из окна, у каждого фото, заголовки сверены со статьями);
- все 4 города с числами (−40…+50), все 3 курса, каждый отличается от вчерашнего не больше чем на 5%;
- кадры §4 проверены, ролик доступен по raw-ссылке.
Иначе — НЕ публикуй, пришли MP4 (если есть) и напиши, что не так.

## 7. Публикация (YouTube API)
`youtube/requests/subh-<D>.json`:
```json
{
  "video": "subh/videos/<D>.mp4",
  "title": "Хабархои шаб, обу хаво ва курби асъор барои имруз",
  "description": "<текст ниже>",
  "tags": ["хабар","ахбор","хабархои шаб","ахбори точикистон","обу хаво","курби асъор","точикистон","таджикистан",
           "новости таджикистана","новости","погода","курси долар","душанбе","худжанд","бохтар","кулоб","хоруг","исфара",
           "азия плюс","asiaplus","ахбори озоди","ахбори руз","таджики","мигрант"],
  "privacy": "public",
  "categoryId": "25",
  "publishAt": "<D>T07:00:00+05:00",
  "thumbnail": "subh/videos/<D>.jpg"
}
```
Заголовок — ровно такой, простыми буквами (так ищут зрители). Описание — **нормальная таджикская грамматика с буквами
ҳ ҷ қ ғ ӯ ӣ** (решение пользователя 21.11.2026); строки через `\n`:
```
Хабарҳои шаби гузашта ва обу ҳаво барои имрӯз — <день> <месяц>

1. <заголовок 1>
… (все пункты, как в ролике)

Обу ҳаво (meteo.tj): Душанбе <mx>°/<mn>°, Хуҷанд …, Бохтар …, Хоруғ …
Қурби асъор (БМТ, сомонӣ): 1 RUB — <v>, 1 USD — <v>, 1 EUR — <v>

Муфассал дар давоми рӯз: asiaplus.news
Манбаъҳо: <корневые адреса источников новостей через « · »> · meteo.tj · nbt.tj
#хабар #ахбор #обухаво #курбиасъор #точикистон #asiaplustj
```
(Хештеги — простыми буквами, как раньше: это поисковые метки.)
Commit «subh: публикация <D>», push (отказ — `git pull --rebase` и снова), затем
`for i in $(seq 1 90); do [ -f youtube/published/subh-<D>.json ] && break; sleep 10; git pull -q --rebase; done`
(Bash, таймаут 600000; обложка ставится после обработки ролика, поэтому результат может прийти на несколько минут
позже — если цикл кончился, повтори его ещё раз, заявку НЕ трогай). `ok:true` — готово; поле `thumbnail`: "ok" —
обложка стоит, иначе текст ошибки (ролик всё равно опубликован — упомяни в отчёте). `ok:false` или таймаут — сообщи; **повторно не загружай и другим путём
не публикуй** (будет дубль). Если push заявки отклонён системой разрешений — не обходи, сообщи и приложи MP4.

## 8. Отчёт
SendUserFile (MP4), затем одно SendUserMessage: статус и ссылка YouTube, встала ли обложка; нумерованные заголовки (таджикский) с коротким
переводом на русский и ссылкой на источник; температуры по городам и курсы с изменением; каких источников не было.
Правки после публикации: перерендер, новая заявка `subh-<D>-v2`; старый ролик пользователь удаляет в YouTube Studio сам.
