# «Хабарҳои шаб» — ежедневный выпуск (YouTube Shorts, Азия-Плюс)

Главное за ночь (с 18:00 вчера до утра) со всех источников: 1 главная новость крупно + до 5–6 коротких заголовков,
20 с, таджикский язык. Публикация в **07:00** через YouTube Data API (GitHub Action `youtube-upload`) —
**автоматически, без согласия пользователя** (решение пользователя 06.11.2026: он в это время спит). Metricool не используется.
Длительность ~27 с: главная 5 с, пункты по очереди до ~18 с, затем весь список держится ~8 с, чтобы дочитали.
Отвечай пользователю по-русски, в начале каждого сообщения — дата и время. Пользователь не следит за работой:
всё, что он должен прочитать, — через SendUserMessage; файлы — SendUserFile со status "proactive".
Заведи список задач и иди по шагам без вопросов — пользователю ничего не задавай.

## 1. Подготовка
- Текущее время (Asia/Dushanbe): D — сегодня, P — вчера. Окно новостей: `P 18:00` → сейчас.
- `add_repo` asiaplustj-del / asiaplus-dobroe-utro, access push → `git clone --depth 1` в /home/claude/repo
  (таймаут 10 мин). `git config user.name asiaplustj-del; git config user.email jadidasiaplus@gmail.com`.
- Окружение: `python3 -c "import playwright, numpy"` и `ffmpeg`. Нет — `pip install --break-system-packages playwright numpy`,
  `python3 -m playwright install chromium`.

Важно: среда Claude не открывает сайты-источники напрямую. Всё скачивает GitHub Action `khabar-fetch`:
кладёшь список в `khabar/requests/<id>.txt` → commit → push → `bash khabar/wait.sh <id>` (запускай через Bash
с run_in_background и дождись уведомления) → результат в `khabar/fetched/<id>/`, отчёт в `_done.json`.
Формат строки: `page <имя> <url>` (HTML/RSS), `og <имя> <url статьи>` (главное фото статьи), `img <имя> <url картинки>`.

## 2. Сбор
- `cp khabar/sources.txt khabar/requests/<D>.txt`, commit «khabar: ленты <D>», push, дождаться wait.sh.
- `python3 khabar/collect.py khabar/fetched/<D> --since "<P> 18:00"` → список кандидатов со временем, ссылкой, фото.
- Если какой-то источник в `_done.json` с ok:false — просто учти, что его нет (сообщишь в отчёте одной строкой).

## 3. Отбор и заголовки
Отбирай сам — что важнее и интереснее **большинству жителей Таджикистана** (простой популярный контент):
- В приоритете: то, что касается денег, работы, миграции, цен, курса, законов и правил для людей, здоровья,
  безопасности (землетрясения, ДТП с жертвами, погода-ЧП), крупных решений власти, громкого спорта (таджики в UFC,
  сборная, «Истиклол»), заметных событий в соседних странах и мире — максимум 1–2 мировые.
- Не брать: реклама/промо/«партнёр рубрики», протокольные встречи, конференции, форумы, поздравления, гороскопы,
  дайджесты «Салом алейкум/Субҳ ба хайр», пропаганду и колонки-мнения.
- Редакционная линия: «Азия-Плюс» — лояльное СМИ, не симпатизирует оппозиционным активистам. Новости вроде
  «активисту грозит экстрадиция в Таджикистан» либо не брать, либо писать нейтрально: «могут экстрадировать»,
  а не «грозит» (решение пользователя 04.11.2026).
- Одна история из нескольких источников = один пункт. Новости вне окна — не брать.
- Всего 6 пунктов (минимум 4, максимум 7). Первый — главная (самое резонансное, лучше с хорошим фото).
- Если суть не ясна из ленты — прочитай статью (WebFetch по ссылке) и пиши только факты из неё.

Заголовки (поле `text`):
- Таджикский литературный, очень простой и понятный всем; без уличных русизмов; кириллица с ҳ ҷ қ ғ ӯ ӣ.
- Одна короткая фраза, 35–65 знаков, без оценок и кликбейта, без точки в конце.
- Деньги — знак перед суммой: `$1200`, `€500`; сомони — «1200 сомонӣ». Цифры — цифрами.
- Имена и названия — как в источнике на таджикском. Источник на экране НЕ указывать.
- Категория `cat`: muhojirat (миграция), hodisa (происшествия, ЧП), siyosat (власть, политика), qonun (законы, суды,
  правила), tandurusti (здоровье), varzish (спорт), iqtisod (экономика, цены, курс), jahon (мир), jomea (общество),
  obuhavo (погода).

## 4. Фото
- Запрос `<D>-img.txt`: для каждого пункта `og n<k> <url статьи на сайте>`; для поста Telegram с фото —
  `img n<k> <url картинки из collect.py>`. Commit, push, wait.sh.
- Скопируй в рабочую папку `img/`. Посмотри контакт-лист (ffmpeg hstack/vstack → Read). Не подходит: логотип, аватар
  канала, файл < 15 КБ, фото не по теме, обложка/заставка с текстом поверх или с ведущим (ТВ-выпуски Озоди и т. п.).
- **Фото обязательно у КАЖДОГО пункта — без исключений, фирменный фон не использовать.** Порядок поиска:
  1) иллюстративное фото со страницы самой новости; 2) фото той же истории из других источников;
  3) если и там нет — WebSearch по теме (объект, учреждение, явление: «Рогунская ГЭС», «Green Card», «гадалки» и т. п.)
  и `og` со страниц найденных статей любых СМИ. Отправь второй запрос `<D>-img2.txt` с несколькими кандидатами на
  пункт, выбери лучший по контакт-листу. Не отправляй выпуск, пока у всех пунктов нет подходящего фото.

Публикуй только если всё верно, иначе — НЕ публикуй и сообщи пользователю (шаг 9), что не так, приложив MP4:
- минимум 4 пункта, все из окна `P 18:00` → сейчас, у каждого — подходящее фото;
- каждый заголовок сверен со статьёй-источником (факты, цифры, имена); редакционная линия шага 3 соблюдена;
- кадры 3.5 с и 24 с проверены: текст не обрезан, буквы ҳ ҷ қ ғ ӯ ӣ на месте, `fs` ≥ 40;

Сомнительную новость лучше выкинуть (оставив ≥ 4 пункта), чем публиковать.

## 8. Публикация на YouTube (API)
Заявка `youtube/requests/khabar-<D>.json` (id обязательно с префиксом `khabar-`, чтобы не пересечься с «Доброе утро»):
```json
{
  "video": "khabar/videos/<D>.mp4",
  "title": "Хабархои шаб — <день> <месяц>",
  "description": "<текст ниже>",
  "tags": ["хабар","ахбор","хабархои шаб","ахбори точикистон","точикистон","таджикистан",
           "новости таджикистана","новости","душанбе","азия плюс","asiaplus","мигрант","ахбори руз"],
  "privacy": "public",
  "categoryId": "25",
  "publishAt": "<D>T07:00:00+05:00"
}
```
- `<день> <месяц>` — по-таджикски простыми буквами, напр. «27 октябр», «7 ноябр».
- `description` (простыми буквами, без ҳ ҷ қ ғ ӯ ӣ — так ищут зрители; строки через `\n`):
  ```
  Хабархои шаб — <день> <месяц>
  1. <заголовок 1 простыми буквами>
  … (все пункты)
  Муфассал дар давоми руз: asiaplus.news
  Манбаъхо: <корневые адреса использованных источников через « · »>
  #хабар #ахбор #хабархоишаб #точикистон #asiaplustj
  ```
- `publishAt` — ролик загружается сразу как отложенный и сам становится публичным в 07:00. Если до 07:00 меньше
  2 минут или уже позже — upload.py публикует сразу (поле можно оставить как есть).
- Commit «khabar: публикация <D>», push (при отказе — `git pull --rebase` и снова push), затем
  `bash youtube/wait.sh khabar-<D> 900` (через Bash с run_in_background, дождаться уведомления).
- Результат `youtube/published/khabar-<D>.json`:
  - `ok:true` и (`publishAt` задан или `privacy:"public"`) — готово;
  - `ok:true`, но `privacy:"private"` без `publishAt` — YouTube принудительно закрыл ролик (не пройден аудит API):
    сообщи пользователю, ссылку дай, повторно не загружай;
  - `ok:false` или таймаут — сообщи ошибку. **Повторно не загружай и в Metricool не публикуй** (будет дубль).

## 9. Отчёт пользователю
SendUserFile (MP4, proactive), затем одно SendUserMessage:
- статус одной строкой: «Опубликовано / поставлено на 07:00 — <ссылка YouTube>» или что не получилось и почему;
- нумерованные заголовки (таджикский) и под каждым короткий перевод на русский + ссылка на источник;
- одной строкой — каких источников не было, если были сбои.
Если пользователь потом попросит правки — исправь, перерендерь (шаг 5) и скажи, что старый ролик надо удалить в
YouTube Studio вручную (ключ API только на загрузку); новую заявку делай с id `khabar-<D>-v2`.
